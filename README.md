# Customer-Shopping-Behavior-Analysis

Customer Shopping Behavior Analysis project using Python, PostgreSQL, SQL, and Power BI.

## Project Overview

This project focuses on analyzing customer shopping behavior to identify insights related to customer demographics, purchase patterns, product categories, subscriptions, discounts, customer segments, and revenue.

The project demonstrates the complete data analysis workflow, including data cleaning, feature engineering, SQL analysis, and interactive dashboard creation.

## Tools Used

* Python – Data cleaning, exploration, and feature engineering
* Pandas – Data manipulation and analysis
* PostgreSQL – Data storage and analysis
* SQL – Business analysis using queries
* Power BI – Interactive dashboard and data visualization
* GitHub – Project documentation and portfolio hosting

## Data Preparation

The dataset was cleaned and prepared using Python and Pandas.

The following tasks were performed:

* Explored the dataset and checked data types
* Identified missing values
* Filled missing values in the Review Rating column
* Standardized column names
* Created an `age_group` column
* Created a `purchase_frequency_days` column
* Loaded the cleaned data into PostgreSQL

## Dashboard Features

The Power BI dashboard includes:

* Total Customers
* Average Purchase Amount
* Average Review Rating
* Revenue by Category
* Revenue by Gender
* Revenue by Age Group
* Customer Segmentation
* Subscription Analysis
* Interactive filters for Subscription Status, Gender, Category, and Shipping Type

## Key Insights

The analysis identified insights related to:

* Revenue contribution by gender
* Revenue performance across different age groups
* Product and category performance
* Discount usage patterns
* Subscriber and non-subscriber behavior
* Customer loyalty and repeat purchases
* Purchase frequency
* Shipping preferences

## Project Workflow

1. Loaded and explored the customer shopping behavior dataset using Python.
2. Cleaned the data and handled missing values.
3. Performed feature engineering by creating `age_group` and `purchase_frequency_days`.
4. Loaded the cleaned dataset into PostgreSQL.
5. Performed data analysis using SQL queries.
6. Connected PostgreSQL to Power BI.
7. Created an interactive dashboard to visualize customer shopping behavior.
8. Published the project files and documentation on GitHub.

## Dashboard

The dashboard provides an interactive view of customer shopping behavior and purchasing patterns.

Users can filter the data by:

* Subscription Status
* Gender
* Category
* Shipping Type

The visuals update dynamically based on the selected filters.
